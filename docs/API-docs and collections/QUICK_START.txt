                     VERIFY TOKEN IS WORKING
================================================================================

After running ANY request:

1. Look at "Authorization" header
   Should show: Bearer <actual-token-value>

2. Check Postman Variables tab
   {{accessToken}} should be filled with token string

3. Look at test results
   Green ✅ = Tests passed
   Red ❌ = Check Authorization header

If 401 Unauthorized:
  • Login request may have failed
  • Check test script output in login response
  • Try login again manually first

================================================================================
                    TROUBLESHOOTING
================================================================================

ERROR: ECONNREFUSED 127.0.0.1:3002
FIX: Backend not running
  $ cd apps/api && npm run dev

ERROR: 401 Unauthorized on all requests
FIX: Token not extracted or expired
  • Run login request first
  • Check Variables tab - {{accessToken}} should be filled
  • Look at "Tests" tab in login response for green checkmarks

ERROR: 404 Not Found
FIX: Endpoint doesn't exist or wrong port
  • Verify baseUrl = http://localhost:3002 in Variables
  • Check backend logs for route registration
  • Verify backend is running and port is 3002

ERROR: No data returned
FIX: Database might be empty
  • Create data first using POST requests
  • Or check database has test data seeded
