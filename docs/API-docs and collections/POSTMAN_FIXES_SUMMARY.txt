================================================================================
                          TOKEN FLOW
================================================================================

How Tokens Are Managed (Automatic):

  1. Rep Login Request
     ↓
     Response: { "data": { "accessToken": "eyJ...", ... } }
     ↓
     Test Script: pm.collectionVariables.set('repAccessToken', token)
     ↓
     Stored: {{repAccessToken}} = "eyJ..."

  2. All Rep API Requests Use Token
     ↓
     Header: Authorization: Bearer {{repAccessToken}}
     ↓
     Postman Substitutes: Authorization: Bearer eyJ...
     ↓
     Backend Validates: ✓ Valid token ✓ User role = SALES_REP

  3. Rep Logout
     ↓
     Session Ends, Token Cleared
     ↓
     Ready for Manager Login

  4. Manager Login (Same Process)
     ↓
     {{managerAccessToken}} Stored
     ↓
     All Manager APIs Use Manager Token

NO MANUAL TOKEN COPYING NEEDED - ALL AUTOMATIC!
