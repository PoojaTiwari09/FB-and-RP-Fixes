Screen Name: Calls List
Route: /calls
Purpose of Screen: Display all recorded calls with filtering, search, and status
                   overview. Allows the user to navigate into individual call
                   records.
================================================================================


CALLS — LIST & FILTERS
--------------------------------------------------------------------------------

1. GET /api/calls

    Purpose:
    Fetch paginated list of all calls with applied filters.

    User Action:
    Land on Calls List screen / Apply status, duration, deal type,
    account, participant, owner, or date range filters / Search by keyword

    Request:
    - page
    - size
    - search
    - status               (all | completed | processing | failed | skipped)
    - duration             (all | lt2 | 2to10 | gt10)
    - dealType
    - account
    - participantId
    - ownerId
    - dateRange            (last7days | last30days | custom)
    - startDate
    - endDate

    Response:
    - totalCount
    - page
    - size
    - calls[]
        - callId
        - callTitle
        - dealType
        - account
        - owner
            - ownerId
            - ownerName
            - avatarInitials
        - dateTime
        - duration
        - keyInsight
        - status           (completed | processing | failed | skipped)

--------------------------------

2. GET /api/calls/:callId

    Purpose:
    Fetch full detail of a single call record on row click.

    User Action:
    Click on a call row in the calls list table

    Request:
    - callId               (path param)

    Response:
    - callId
    - callTitle
    - account
    - type                 (outbound | inbound)
    - dealType
    - date
    - time
    - duration
    - source
    - participants[]
        - name
    - owner
        - ownerId
        - ownerName
        - avatarInitials
    - status

--------------------------------

3. GET /api/calls/accounts

    Purpose:
    Fetch list of accounts to populate the Account filter dropdown.

    User Action:
    Click Account filter dropdown on Calls List screen

    Request:
    - search

    Response:
    - accounts[]
        - accountId
        - accountName

--------------------------------

4. GET /api/calls/participants

    Purpose:
    Fetch list of participants to populate the Participants filter dropdown.

    User Action:
    Click Participants filter dropdown on Calls List screen

    Request:
    - search
    - accountId

    Response:
    - participants[]
        - participantId
        - name

--------------------------------

5. GET /api/calls/search

    Purpose:
    Search calls by keyword, account name, or owner name.

    User Action:
    Type in the search bar at the top right of the Calls List screen

    Request:
    - q
    - page
    - size

    Response:
    - totalCount
    - calls[]
        - callId
        - callTitle
        - account
        - owner
        - status
        - dateTime
        - duration
        - keyInsight

13. POST /api/calls/:callId/briefs/:briefId/share-internal

TRANSCRIPT & ANALYSIS
--------------------------------------------------------------------------------

22. GET /api/calls/:callId/transcript

    Purpose:
    Fetch the full call transcript with speaker labels, timestamps,
    and confidence scores.

    User Action:
    Open Transcript & Analysis tab / Type in Search transcript field
    / Toggle Show low-confidence only filter

    Request:
    - callId               (path param)
    - page
    - size
    - search
    - showLowConfidenceOnly (boolean)

    Response:
    - totalCount
    - transcript[]
        - entryId
        - timestamp
        - speakerName
        - speakerType      (rep | customer)
        - text
        - confidence       (high | low)

--------------------------------

23. GET /api/calls/:callId/transcript/summary

    Purpose:
    Fetch AI-generated summary of the call displayed in the AI Summary panel.

    User Action:
    Open Transcript & Analysis tab — AI Summary panel auto-loads

    Request:
    - callId               (path param)

    Response:
    - summary
    - generatedAt

--------------------------------

24. GET /api/calls/:callId/transcript/talk-ratio

27. GET /api/calls/:callId/next-steps

    User Action:

    Request:
    - callId               (path param)

    Response:

        - description

--------------------------------

28. PATCH /api/calls/:callId/next-steps/:stepId

    Purpose:

    User Action:

    Request:
    - callId               (path param)

    - completed            (boolean)

    Response:
    - stepId
    - completed
    - updatedAt
